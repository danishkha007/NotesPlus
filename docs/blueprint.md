# **App Name**: NotesPlus Pro

## Core Features:

- Google Sign-In Authentication: Secure user authentication via Google Sign-In using Firebase Authentication, providing access to protected content.
- SEO-Optimized Landing Page: A high-converting, SEO-optimized homepage with semantic HTML, meta tags, and fast loading speed.
- Global Search: A global search bar in the navbar enabling users to search for notes by subject name, stream, or keywords.
- Notes Detail Page: Display note details including title, description, stream, subject, and file downloads for PDFs, Word documents, and video links.
- AI-Powered Recommendations: Suggest relevant notes using an AI-powered recommendation tool based on the current category or popular downloads.
- Admin Dashboard: Secure admin-only area for CRUD operations on notes, file uploads to Firebase Storage, and metadata management.
- Firestore Integration: Store user data, streams, subjects, and notes in Firestore with defined data structures for efficient data management.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey professionalism and trust.
- Background color: Very light blue (#E8EAF6) for a clean and unobtrusive background.
- Accent color: Complementary orange (#FF9800) to highlight calls to action and important elements.
- Body font: 'PT Sans' (sans-serif) for a modern and readable text.
- Headline font: 'Space Grotesk' (sans-serif) for headlines and emphasis, pairing well with the body font for contrast and legibility.
- Use clean, professional icons from Angular Material's icon set, ensuring consistency and clarity.
- Employ a responsive grid layout using Angular Material's grid system for optimal viewing across devices.
- Implement subtle animations and transitions using Angular Material's animation capabilities to enhance user experience.
